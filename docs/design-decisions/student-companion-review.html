Room queues

Find the room. Keep the ticket.

A searchable queue board and a distinct personal ticket, with honest wait estimates, arrival requirements and server-confirmed actions.

Location is requested only when required. Joining, retrying and cancellation are verified against backend-shaped responses.

Campus assistant

A conversation, not another dashboard.

Capability-backed starting points, a quieter conversation library and a readable transcript that keeps the next action close.

Failed drafts survive. Pending operations cannot mix conversations. Suggested links are limited to real, supported web destinations.

Your account

Personal details. Clear boundaries.

An identity-led account page with separate personal, security and access sections. The shared page works for students, staff and administrators.

Password changes include confirmation and sign-out. Profile saves preserve the session’s permissions and assigned scopes.

Notification inbox

Read what matters. Carry on.

An activity-first inbox with explicit read states, page-level search, server pagination and role-aware destinations.

Rejected reads stay unread. Confirmed reads update the shell badge. Disconnected status and unavailable browser push are stated plainly.
